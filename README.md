# zfl-42 小型漆线雕工坊管理

零构建静态应用 + 零依赖 Node 数据服务。

- 直接双击 `index.html`：工坊看板可离线使用（localStorage）。
- 完整使用「版权授权台」：在仓库根目录运行 `node licensing/server.js`，浏览器打开 <http://localhost:4217/>。

## 版权授权与版税计提台

- **纹样登记**：纹样、作者、题材、登记日期。
- **授权登记**：独占/普通、权利期、可用地区、可用品类、阶梯费率、年度保底。
- **独占排他**：同一纹样的地区 × 品类 × 时间区间重叠时，任一为独占即冲突；服务端对全部写事务在
  单事件循环内同步完成「校验—写入—落盘」，两个页面同时提交也只会有一条成功。
- **历史留痕**：续期、提前终止、要素变更均只追加事件版本，刷新后可完整回溯；终止后不可续期。
- **版税计提**：回款销售按超额累进阶梯费率逐期计提，年度保底折月保底，当月计提不足时差额作为
  保底抵扣补足；逐期表格展示销售、退货、净额、计提、保底抵扣、应付。
- **账期与时钟**：按**真实本地日期**推进，未到期月份不预提款、不允许上报未来账期或预终止；
  测试可通过环境变量 `LICENSING_NOW=YYYY-MM-DD` 注入时钟（仅环境变量，HTTP 头不可注入），
  `GET /api/clock` 可核对当前账期日。
- **条款分段**：保底/阶梯费率变更只能从**未来月份**起生效（默认下一起账月），形成只追加的
  `terms` 分段；每个账期严格按当月生效条款计提，**既往账期绝不重算**。权利要素（地区/品类/
  独占/被授权方）变更仍走冲突校验，冲突时整次修改回滚。
- **数据迁移**：数据文件带 `schemaVersion`（当前 v2）。v1 旧数据首次加载时自动迁移——
  用原 `tiers/guarantee` 反推出起始月条款分段、追加一条 `migration` 历史事件；
  **上报流水原样保留、不重算、不丢失**，二次启动迁移幂等。
- **退货冲减**：必须挂原销售上报，按原销售账期逐期冲回版税（退货晚于销售月也冲回原月，
  并按该月当时生效的费率计算冲回额）；重复退货单号、跨授权上报、退货超过同期销售一律拒绝。
  销售上报凭凭证号（幂等键）去重。
- **批量导入**：JSON 数组一次导入，在数据副本上整批校验，任一条失败全部回滚并返回每条失败明细。
- **持久化**：数据写入 `licensing/data/data.json`（临时文件 + rename 原子替换），刷新/重启一致。

## 测试（支持含空格路径、任意 cwd，不依赖固定端口/主机路径）

```bash
node licensing/tests/run-all.mjs   # 一键：接口测试 + 真实 Chromium 走查
# 或分别运行
node --test licensing/tests/api.test.mjs
node licensing/tests/e2e.mjs
```

- 测试服务一律用 `PORT=0` 由系统分配端口，数据文件放 `os.tmpdir()` 临时目录，用 `fileURLToPath`
  解析路径，因此可从任意工作目录、含空格/中文的路径直接运行；Playwright 缺失时浏览器用例自动跳过。
- 覆盖：真实/注入时钟、v1→v2 迁移且流水不变、未来账期/预终止拒绝、跨月与跨年条款分段、
  月末终止边界（当月可报/次月拒绝/区间释放）、独占并发、阶梯+保底、退货三类拒绝、批量回滚、
  刷新与重启一致、原授权全流程与工坊看板回归。

## 接口

| 方法 | 路径 | 说明 |
| --- | --- | --- |
| GET | `/api/state` | 纹样 / 授权 / 上报流水 / 逐期计提汇总 |
| GET | `/api/clock` | 当前账期日、是否注入时钟、schema 版本 |
| POST | `/api/motifs` | 登记纹样 |
| POST | `/api/licenses` | 新建授权（独占冲突 409） |
| POST | `/api/licenses/:id/renew` | 续期 |
| POST | `/api/licenses/:id/terminate` | 终止 |
| POST | `/api/licenses/:id/change` | 变更（冲突自动回滚字段修改） |
| POST | `/api/reports/sales` | 回款销量上报（幂等键） |
| POST | `/api/reports/return` | 退货冲减（原销售、原账期） |
| POST | `/api/batch/licenses` | 批量导入，失败整批回滚 |
| POST | `/api/reset` | 恢复演示数据 |

## 工坊看板（原有功能）

新增作品（胎体/纹样/线条/进度/阴干/金粉/缺陷/交付）、四列工序看板、今日待阴干、缺陷作品、
最近交付、状态流转、缺陷记录、筛选排序、localStorage 持久化与 JSON 导出。
